# Adobe Replacements

Open-source, clean-room Rust reimplementations of Adobe tools, imported from [github.com/storytold](https://github.com/storytold) (shallow snapshots of each `main` branch, history not included). Each directory keeps its original README and Apache-2.0/MIT licenses.

| Directory | Replaces |
|---|---|
| `photocraft/` | Photoshop |
| `lightcraft/` | Lightroom |
| `filmcraft/` | Premiere Pro |
| `pdfcraft/` | Acrobat |
| `vectorcraft/` | Illustrator |
| `effectcraft/` | After Effects (see its README) |
| `designcraft/` | InDesign (see its README) |

Source repos: `storytold/<name>`.
