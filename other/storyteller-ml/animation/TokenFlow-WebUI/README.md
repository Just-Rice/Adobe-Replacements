# TokenFlow-WebUI
 
## Installation

### Using Anaconda on Windows/Linux (Recommended)

1. **Clone the repository:**
    ```bash
    git clone https://github.com/justinjohn0306/TokenFlow-WebUI.git
    cd TokenFlow-WebUI
    ```

2. **Create a new Anaconda environment named `tokenflow` with Python 3.9:**
    ```bash
    conda create -n tokenflow python=3.9
    ```

3. **Activate the `tokenflow` environment:**
    ```bash
    conda activate tokenflow
    ```

4. **Install the required packages:**
    ```bash
    pip install -r requirements.txt
    ```

## Running the App

After you've installed all the required packages, you can launch the Gradio app by running the following command:

```bash
python app.py
