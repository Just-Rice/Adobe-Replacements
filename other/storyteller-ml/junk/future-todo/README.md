TalkNet
=======
TalkNet is not currently in a usable state. Ideally we can have both Tacotron and 
Talknet models operate at the same time from the same uniform codebase.

The reason we want them to work together is so that we can leverage the same GPU
resources and use LRU in-memory caching.
